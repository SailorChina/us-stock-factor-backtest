# us-stock-factor-backtest

美股因子策略的回测、验证与实盘信号工具集。数据源为**富途 OpenD**，当前覆盖 **81 只美股**（2018-01 ~ 2026-09），完整记录了从因子筛选、深度审计、熊市防御、资金无关性验证到**全策略统一排名**的全过程。

> **⚠️ 免责声明**
> 本项目是**研究记录与工具**，不是投资建议。所有回测结果均基于历史数据，**不预示未来收益**。
> 项目自带的缺陷清单（见 [`美股系统剩余缺陷清单_v20.md`](美股系统剩余缺陷清单_v20.md)）明确列出了幸存者偏差、
> 多重比较、收益集中、熊市样本不足等**无法通过代码修复**的结构性问题。
> 按此策略交易的任何盈亏由使用者自行承担。

## 这个项目是什么

- ✅ 一个**日级事件驱动回测引擎**：T 日收盘算信号 → T+1 开盘价成交，含真实佣金、碎股
- ✅ 一套**因子交叉验证**流程：Vortex / 动量−1月反转 / 经典 12-1 动量 / 均线择时 / 技术指标全家桶
- ✅ 一个**全策略统一排名**（[`美股全策略总排名_v26.md`](美股全策略总排名_v26.md)）：69 个策略在同一引擎、同一池子、同一区间、同一成本下重跑并排序
- ✅ 一个**每日可用的一键下单助手**：自动刷新行情、算信号、出可执行的换仓清单
- ✅ 一份**诚实的缺陷档案**：每个结论都附基准校准、稳健性检验和已知反例
- ✅ 一个**可复现的审计流程**：[`美股回测深度审计_v25.1.md`](美股回测深度审计_v25.1.md) 记录了 3 个"不报错、只让结果悄悄变好"的真实缺陷及其修复

## 这个项目不是什么

- ❌ 不是「稳赚策略」。回测里的天文数字包含**幸存者偏差**（标的池是 2026 年筛出来的赢家名单）
- ❌ 不是高频/日内系统。调仓周期默认 **21 个交易日**（约 1 自然月）；v27 起可用
  `--rebal` 切到 **10 个交易日**（v26 风险调整冠军：回撤 −35.8% vs −65.0%）
- ❌ 不保证选股永远正确。频率与相位对最终收益的解释力只有 4~7%，其余是运气
- ❌ **排行榜不是选股指南**。全策略排名的第一名（金叉+MA50距离 Top2）是在**同一批数据上试过几十个策略**后挑出来的，必然含运气成分（见下）

## 结论速览

| 项目 | 数值 |
|---|---|
| 主策略 | **Vortex Top2 等权满仓**，默认每 21 个交易日调仓（`--rebal` 可调） |
| 标的池 | **81 只**（市值 ≥ $100 亿的非 ETF），数据 2018-01-02 ~ 2026-09-11 |
| 实际投资窗口 | **2019-01-03 ~ 2026-09-11（7.69 年）** —— 前 252 根只用于因子预热，不参与投资 |
| Vortex Top2（$2/笔双边佣金，闸门，本金 $3,000） | **$110,856**（+3,595%），CAGR 59.9%，最大回撤 −65.0% |
| **Vortex Top2 @10日调仓**（同上口径） | **$504,672**（+16,722%），CAGR 94.8%，最大回撤 **−35.8%**，夏普 1.67，8 年全正 |
| Vortex Top2（零闸门，纯信号） | $89,538（+2,885%），CAGR 55.4% |
| 真实基准（81 只等权买入持有） | +1,566%（$49,988），CAGR 44.2%，最大回撤 −40.0% |
| VOO 同期 | +252%（$10,565），CAGR 17.8%，最大回撤 −34.0% |
| 交易成本 | 富途美股 **$2/笔**（买 $2 + 卖 $2），按笔固定、不分股数 |
| 实盘本金口径（v28） | 本金 **$1,490** 下佣金拖累 **5.45pp**（10 日）／2.88pp（21 日）；**冠军仍是 10 日**（CAGR 93.1% vs 58.4%）。拖累 ≈ 7,700 ÷ 本金 |
| 执行成本（v29） | 滑点可忽略（$745 订单占成交额 **0.0009%**）；**时点才是成本** —— 拖到收盘成交，10 日调仓 **−4.21pp**、21 日 −0.93pp。综合口径 ≈ **91.4%** CAGR（理想 98.5%） |
| 相位稳健性（v30） | 调仓周期是**相位**不是参数：anchor 平移 1 天，10 日 CAGR 就在 **51.3%~100.6%** 摆动（极差 49.3pp）。但 **10 日冠军不是相位运气** —— 中位领先 21 日 **+21.9pp**、随机配对胜率 **76.7%**、4 种口径一致。**正确读法：期望 81%，落点 51%~101%** |
| 错开调仓（v31） | 「错开两腿调仓日」看起来零成本（笔数确实不变），但**不是免费午餐**：引入**两腿不等权**（偏离 50/50 平均 **32.3%**），全部 offset 都是「用中位换下限/换离散度」的互换。**等权版错开佣金 ~2.3 倍，买不起** |
| 因子窗口（v32） | Vortex 的窗口 `n=14` 是全项目写死的**习惯值**，从未扫过。实测 **`n=14` 在 10 日调仓下就是 8 个窗口里的第 1 名**（对其它 7 个全胜）⇒ **不用改**。但 **「10 日 > 21 日」只在 4/8 个窗口下成立**，且 `n=14` 恰好是 10 日领先最大的窗口（+21.9pp）⇒ 周期结论**带"在 n=14 上看"的选择性** |
| 引擎自检 | **10 项全过**，含两条恒等式：调仓价值守恒（13,874 次）+ 无成交日价格归因（126,370 天） |

> **基准校准是本项目最重要的方法论**：拿 VOO 当基准会把超额夸大 3 倍以上。
> 只有跑赢「闭眼全买这一池子」才算真 alpha。
>
> **CAGR 口径**：按**实际投资年数**（7.69 年）计算，不是数据跨度（8.7 年）。
> 把预热期算进年数会**低报** CAGR，把数据跨度当投资年数会**高报** CAGR —— 两者都错。

## Windows 一键入口（推荐）

双击项目根目录的 **`一键运行.bat`**（想放桌面：右键 → 发送到 → 桌面快捷方式），按数字键选：

| 键 | 做什么 | 说明 |
|---|---|---|
| `1` | **每日实盘信号更新** | 自动检查 Futu OpenD 端口 11111；没开就用桌面快捷方式拉起并等待就绪，然后按你选的本金 / 周期跑 `_update_signal.py`，跑完直接显示今日选股 |
| `2` | **完整回测重跑** | `$3,000` 与 `$1,500` 两档全策略排名（69 策略 + 3 基准）；可选 `--fast` 跳过 AI 家族 |
| `3` | **推送 GitHub** | 列出候选文件（临时脚本自动排除）→ 可逐个挑选 → 中文提交 → 推送 → **调 GitHub API 回读校验** |
| `4` | 一键自检 | `_update_signal.py --self-test`（98 项断言） |
| `5` | 查看最新选股快照 | 直接读 `signal_snapshot.json` |
| `0` | 退出 | |

菜单逻辑在 `_menu.py`；`.bat` 只负责找到正确的 Python 解释器然后调用它。
四条硬规则已固化在代码里：

- **绝不 `git add -A`** —— 只提交你在菜单里确认过的显式清单；
- **提交信息先落盘成 `.txt` 再 `commit -F`** —— 在 Bash 里内联写中文信息，`$3000` 会被 shell 吞成 `000`；
- **推送用 `origin HEAD:main`** —— 本机 remote-tracking 引用建不起来，`-u` / `--force-with-lease` 会报 stale info。
- **`一键运行.bat` 必须存成 ANSI/GBK(936) + CRLF，且绝不能在里面写 `chcp`** —— cmd.exe 是**按字节偏移边读边执行**批处理文件的；文件里一旦执行 `chcp 65001`，中文从 GBK(2 字节) 变成 UTF-8(3 字节)，后续每一行的读取偏移全部错位、被啃掉几个字符，残余片段会被当成命令执行，报出一串 `'PYTHONUTF8=1' 不是内部或外部命令`。LF-only 换行会加重这个错位。用记事本改完请「另存为 → 编码 ANSI」。

排错：双击后如果看到成串的「不是内部或外部命令」，先按上面这条检查 `.bat` 的编码与换行符（应为 GBK、CRLF、无 `chcp`）。

## 快速开始

```bash
# 1. 依赖（Python 3.12+）
pip install -r requirements.txt

# 2. 直接跑回测（数据已随仓库提供，无需联网）
python _bear_defense_v14.py

# 3. 出今天的下单清单（不联网，用仓库里的数据）
python _update_signal.py --no-fetch

# 3b. 切到 10 日调仓（v26 风险调整冠军）；--anchor 指定日历起点
python _update_signal.py --rebal 10
python _update_signal.py --rebal 10 --anchor 2026-09-14

# 4. 跑全链路自检（103 项断言，含资金无关性、调仓日历、佣金拖累、执行时点、周期相位、错开调仓、因子窗口、闸门阈值、历史表去重、展示层对齐与佣金预留）
python _update_signal.py --self-test
```

> **`--rebal` 是纯日历参数**：它只决定"今天算不算调仓日""下次哪天调"，
> **一个字都不影响选股结果**（自检里有 4 条断言锁死）。
> **执行日只有看到 `⚡` 才是"今晚动手"** —— 工具现在会明确区分
> "该下单 / 已错过 / 还没到"三种状态，别凭感觉下单。
>
> **⚠ 周期数的是【交易日栅格】，不是自然日、也不是"每周一"（v35 补）** ——
> 从 `anchor`（默认面板第 252 根，2019-01-03）起每 `rebal` 个交易日一格，
> 栅格外的日子一律不动。例：上次调仓 2026-09-09、周期 10 → 下次 **2026-09-23**，
> 而不是下周一 09-14。工具会打印 `= 上次调仓 X + N 个交易日（已过 a + 还需 b = N）` 供核对。

需要**拉取最新行情**时，先启动 Futu OpenD（默认端口 11111），然后：

```bash
python _update_signal.py                    # 刷新行情 + 出信号，一步完成
python _fetch_long.py                       # 或只重拉 37 只股票的完整历史
```

> **在别人的机器上运行**：所有脚本里的 `BASE` 路径是硬编码的。换机器先跑一次
> `python set_base.py`，它会自动把 `BASE` 改写成当前目录。


`_rank_all_strategies.py` 的两条恒等式是本项目最有价值的两条断言：

1. **调仓价值守恒**：每次调仓都满足 `卖出前总值 − 卖出后总值 == 卖出笔数 × 佣金`，
   反之亦然。任一次残差不为 0 ⇒ 有资金在换仓过程中凭空出现或消失。
2. **无成交日价格归因**：现金与持仓都没变的日子，净值变动必须 **100% 由持仓自身价格变动解释**。
   任何"凭空少一块"的假断崖都会在这里暴露（比"单日跌幅超过 X%"这种阈值法严格得多）。

> **⚠ 报收益必须同时报相位区间。**总榜那个 CAGR 是"某一天起步"的抽签结果，不是策略属性。
> v34 实测：金叉+MA50距离 Top2 总榜 99.9% 在 21 个相位里排 **4/21**，相位中位 80.4%、区间 46%~117%；
> Vortex@10 总榜 94.8% 排 **2/10**，中位 79.9%、区间 56%~100%。
> **两者中位数几乎打平，但 Vortex@10 最差相位高 10pp、回撤少 21pp** ⇒ 单点排名会骗人。
> 用 `--phase` 扫 `anchor ∈ [START, START+rebal)`。

## 核心概念

### 因子

| 因子 | 公式 | 特点 |
|---|---|---|
| **Vortex**（主策略） | `VI+ − VI−`，14 日窗口；`VI+ = Σ\|high − low₋₁\| / ΣTR` | 趋势家族，回撤控制最好 |
| 动量−1月反转 | `z(close₋₂₁/close₋₂₅₂−1) − z(close/close₋₂₁−1)` | 收益最高但回撤 −83.7%、收益极度集中 |
| 动量 12-1 | `close₋₂₁/close₋₂₅₂ − 1` | 经典学术因子 |

### 三层解耦（v22 的核心设计）

| 层 | 决定什么 | 受资金影响？ |
|---|---|---|
| ① 信号层 | 因子得分排序（买哪只票） | **否** |
| ② 组合层 | 持股数 TopK | **否**（由信号横截面表现决定） |
| ③ 执行层 | 每只买多少股、闲置现金、佣金 | **是（仅此层）** |

选股函数 `select(A, i, good, topk)` 的签名里**不允许出现**本金 / 净值 / 佣金 / 汇率。
`--self-test` 会用 3 条断言持续验证这一点。

> **v28 把第 ③ 层的代价量化了**：碎股 + 零佣金下策略**严格尺度不变**
> （零佣金 CAGR 对 \$500~\$50,000 极差 < 1e-13pp），所以**本金对最终收益的唯一影响
> 就是那 \$2/笔固定佣金** —— 拖累(pp) ≈ 7,700 ÷ 本金（10 日调仓）。
> 本金翻倍，拖累减半。详见 [`美股小资金实盘路径_v28.md`](美股小资金实盘路径_v28.md)。
>
> **v29 再补上"什么时候成交"**：滑点几乎为零（\$745 订单占成交额 0.0009%），
> 但**执行时点有价格** —— 成交价从开盘挪到收盘，10 日调仓 **−4.21pp**、21 日 −0.93pp
> （代价与换手频率成正比）。综合口径 ≈ **91.4%** CAGR。
> 详见 [`美股执行成本与滑点_v29.md`](美股执行成本与滑点_v29.md)。
>
> **v30 再补上第 ④ 层：周期本身是个"相位"，不是参数**。此前所有 CAGR 都只是
> **某一个相位**上的结果 —— anchor 平移 1 天，10 日调仓就在 **51.3% ~ 100.6%** 之间摆动
> （标准差 17.2pp，比任何一项交易成本都大一个量级）。但 10 日的优势**不是相位运气**：
> 中位领先 21 日 **+21.9pp**、随机配对胜率 **76.7%**（161/210）、4 种执行口径一致。
> **正确读法是「期望 81%，落点 51%~101%，取决于起步日」**，而不是「10 日能跑出 97%」。
> 另：在 \$1,490 本金下**相位分散化买不起**（N=2 就吃掉 6.2pp，N=3 吃掉 20.1pp）。
> 详见 [`美股周期相位稳健性_v30.md`](美股周期相位稳健性_v30.md)。
>
> **v31 试了"零成本"的替代方案 —— 错开两腿调仓日**（每只票仍持 \$745、仍每 10 天调一次，
> 只是相差几天调，10 天总成交仍是 2 卖 + 2 买 = \$8）。**成本前提成立**（offset=0 的
> 成交笔数与基线逐相位完全相同），**但它不是免费午餐**：错开会引入**两腿不等权**
> （实测偏离 50/50 平均 **32.3%**，因为基线在同时换票时会免费把权重调回等权），
> 于是**没有任何 offset 能同时改善中位/最差/离散度** —— 全部是「用中位换下限/换离散度」
> 的互换（互换幅度最大的 offset=2：最差 +8.1pp、IQR −20.6pp、σ −6.1pp，代价中位 −3.7pp）。
> 而**等权版错开买不起**（佣金 ~2.3 倍：683 → ~1,570 笔）。
> ⇒ **相位风险在 \$1,490 本金下没有免费的对冲手段。**
> 详见 [`美股错开调仓_v31.md`](美股错开调仓_v31.md)。
>
> **v32 顺着同一条线审「信号本身的参数」**。v30 的教训是「凡是冻在某一个值上、
> 从未扫过的参数，都可能藏着未计价的自由度」—— 而 Vortex 的窗口 `n=14` 就是全项目
> 写死的**习惯值**（69 个策略共用 `vort14`），从未被扫描。实测：窗口确实是个自由度
> （10 日中位从 38.5% 到 81.0%，极差 **42.5pp**），但**小于相位**（同窗口内相位极差
> 最大 **108.7pp**）。**✅ `n=14` 在 10 日调仓下就是 8 个窗口里的第 1 名**
> （对其它 7 个窗口全胜，57%~94%）⇒ **不用改**。
> **⚠ 但「10 日 > 21 日」只在 4/8 个窗口下成立**（在 n=5/7/42/63 下 21 日反而赢），
> 且 `n=14` 恰好是 10 日领先幅度**最大**的窗口（+21.9pp）
> ⇒ **「10 日是冠军」带一点"在 n=14 上看"的选择性**，换因子/换窗口后必须重跑周期比较。
> 详见 [`美股因子窗口敏感性_v32.md`](美股因子窗口敏感性_v32.md)。

## 已知缺陷（无法修复，只能披露）

详见 [`美股系统剩余缺陷清单_v20.md`](美股系统剩余缺陷清单_v20.md)，摘要：

1. **幸存者偏差** —— 标的池是 2026 年按市值筛出来的，本身已是赢家名单
2. **多重比较** —— 试过几十个指标后挑出的冠军必然带运气（前后段排名相关 rho ≈ 0.00）
3. **收益集中** —— 剔除最好 10 个持有期后跑不赢"闭眼全买"
4. **快熊无防御** —— 均线择时能躲 2008 长熊（−56% → −6%），但 2020 快熊只躲掉一半
5. **熊市样本不足** —— 8.7 年只覆盖 2 段熊市
6. **回撤是下限** —— 在幸存者池 + 牛市样本里算出的最大回撤，实战会更深
